# 期刊级科研绘图与结构复现

用于科研论文中的代码原生图件：统计图、机制仿真图、多面板图、论文图结构复现和可复用绘图工程。目标是把“能看出结构”提升为“可投稿、可复核、可维护”的图件模板。

## 能力边界

使用本参考文件：

- 论文数据图、统计图、模型比较图、Kaplan-Meier、生存风险表、Bootstrap 区间、热图、聚类树、雷达图、点区间图、堆叠面积图、时序小多图。
- 用户要求 SVG/PDF/PNG、600dpi、Matplotlib、代码复现、synthetic/demo 数据、assumptions、manifest、自动质检。
- 用户给出论文图、图注、Deep Research 报告或提示词，要求按结构复现而不是复制像素。

不要使用本参考文件抢占其他能力：

- 对话内交互演示、可调参数小工具、地图或即时可视化：使用 `visualize`。
- AI 照片、插画、封面、纹理、真实物体、背景替换、透明位图：使用 `imagegen`。
- PPT/slide deck 排版：使用 presentation 相关能力。
- 直接修改 Word/PDF 文件、批注、页面渲染：使用 documents/pdf 能力；本参考只负责图件和图注逻辑。

## 数据生成原则

机制模拟不能是“简单线性函数 + 随机噪声”。按学科图形语法生成：

- 训练曲线：分阶段提升、平台、相关波动和递减波动幅度。
- 临床 KM：先生成患者级事件时间、删失时间和 event indicator，再计算 Kaplan-Meier。
- 纵向临床试验：快速变化期、慢变化期、平台期、访视点误差棒和终点统计分离。
- 排名点区间图：每组不同中位数、不同置信区间宽度、合理竞争群。
- 堆叠面积图：类别增长速率不同，交点数值求解，不手写死。
- 文本小多图：每个语料库不同峰值、转折、斜率、结构突变和置信区间。
- 聚类图：从国家/样本特征矩阵计算 linkage，不手工画树。

## 典型图形路由

- 气象/模型技能图：折线 + 相对差值 + ACC + 多变量热图，发散色标以 0 为中心。
- 强化学习训练图：Elo、预测准确率、MSE 三联图，共享时间轴，不用双 y 轴。
- 医学生存图：2×2 Kaplan-Meier + 风险人数表，风险人数从患者数据动态计算。
- 肥胖/药物纵向试验图：趋势图 + 终点柱图，观察均值和确认性终点分开。
- 结构生物排名图：横向点区间图，中位数排序，突出主方法，其他方法灰色。
- 环境存量图：堆叠面积 + 参照曲线 + 不确定性带 + 数值求解交点。
- 数字人文小多图：4×4 small multiples，行列共享轴规则明确，原始趋势 + 平滑趋势 + CI。
- 计算社会科学聚类图：树状图 + 雷达画像；增强版可用点图 + bootstrap CI 替代雷达。

## 导出与质检

每张正式图输出：

- SVG：文本保持可编辑。
- PDF：嵌入 TrueType 字体，避免全部文字转路径。
- PNG：600 dpi，白底，不透明。
- Preview：按实际宽度预览，并生成 50% 缩放预览。

自动检查至少覆盖：

- 目标画布尺寸和 600 dpi 像素宽度。
- 背景白色、无意外透明。
- 字号不低于 5.8 pt。
- 无调试标题、文件名、`simulated`、`structural reproduction` 等正式稿禁词。
- 面板标号齐全。
- 色条、图例、风险表、误差棒和注释不裁切、不遮挡核心数据。
