# 医学组合图逻辑

本文件专门总结医学材料、病理、免疫荧光、Western blot、动物实验和组织学图片的组合逻辑。它适用于创面修复、炎症调控、肿瘤治疗、药物递送、感染控制和组织再生类论文。

若任务还涉及逆向学习参考论文、抽象可迁移论文骨架、建立用户数据资产表、重设计 Scheme 和 Fig. 1—Fig. N，应同时读取 `24_生物医学材料论文骨架与组图设计.md`。

这里说的“医学组合图”，不是工程框图，也不是单张漂亮插图，而是把一篇医学论文的证据链压缩成若干组面板，让读者按“材料是什么 -> 材料能做什么 -> 细胞是否响应 -> 动物是否有效 -> 组织是否重建”的顺序读下去。

## 1. 医学组合图的本质

- 一张图只回答一个科学问题。
- 每张图至少包含一层代表图和一层定量图。
- 图组顺序必须服务证据链，而不是服务排版。
- 读者应当从图中直接看出：问题、处理、对照、结论、边界。
- 医学组合图优先使用“病理状态 -> 材料干预 -> 体外响应 -> 体内疗效 -> 组织收口”的叙事。

## 2. 默认七图骨架

典型的医学材料/创面修复论文，默认可按七张主图推进：

| 图号 | 任务 | 典型子图组合 |
|---|---|---|
| 图1 | 证明材料做出来了 | SEM / HRTEM / XRD / EDS / XPS |
| 图2 | 证明材料真的有功能 | TMB / O2 / ROS 清除 / 光热 / 释放 / 酶样活性 |
| 图3 | 证明载体能用 | 宏观照片 / SEM / 自愈 / 黏附 / 降解 / 流变 / EPR |
| 图4 | 证明安全且有基础生物效应 | 活死染 / CCK-8 / 抗菌 / 菌落 / 细菌 SEM / 划痕 |
| 图5 | 证明机制桥梁 | ROS / 缺氧 / 免疫荧光 / WB / 极化 / 通路 |
| 图6 | 证明动物疗效 | 建模示意 / 创面照片 / 闭合率 / 菌负荷 |
| 图7 | 证明组织重建 | H&E / Masson / IF / IHC / 定量 |

这套顺序和典型感染创面水凝胶论文高度一致，核心不是“图多”，而是“证据层层加码”。

## 3. 组合规则

### 3.1 一图一问

每张图开始前先问一句：

- 这一图要解决什么问题？
- 这一图的结论是否能被下一图接住？
- 这一图有没有代表图、定量图、统计图三个层次？

如果答案不清楚，这张图通常就还没想透。

### 3.2 先代表，后定量，再解释

医学组合图的标准顺序通常是：

1. 代表图先出现。
2. 对应的统计图紧跟其后。
3. 最后再放机制示意或文字解释。

这样读者先看到现象，再看到证据，再看到解释，不会被文字拖着走。

### 3.3 左右/上下的常用分工

- 左侧通常放材料、处理或模型。
- 中间放中层机制或过程。
- 右侧放结果、统计或对照。
- 上排放宏观图、代表图或流程图。
- 下排放定量图、曲线图或统计图。

### 3.4 对照组必须贯穿全篇

- 同一批核心对照组尽量在所有图里保持一致。
- 同一处理组颜色尽量一致。
- 同一组名称不能前后乱变。
- 体外和体内如果组名不同，要在图注里解释清楚。

## 4. 典型排图逻辑

### 4.1 材料身份图

适合放在第一张图。

推荐顺序：

- 粗粒度形貌：SEM / TEM。
- 晶体信息：HRTEM / XRD。
- 元素分布：EDS mapping。
- 化学态：XPS / FTIR / NMR。

这类图的逻辑是从“看得见”到“证得出”再到“解释得清”。

### 4.2 功能确认图

适合第二张图。

推荐顺序：

- 化学反应或催化现象。
- 氧气/自由基/活性物种变化。
- 光热或响应曲线。
- pH、离子、释放或降解行为。

这一组图的核心不是罗列实验，而是证明材料有“可用的功能轴”。

### 4.3 载体适配图

适合第三张图。

推荐顺序：

- 宏观外观。
- 微观孔结构。
- 自愈和黏附。
- 降解和溶胀。
- 流变恢复或应力响应。

这一组图回答的是：材料不是只有功能，还能否作为敷料、支架或递送平台长期工作。

### 4.4 体外生物基础图

适合第四张图。

推荐顺序：

- 活死染或 CCK-8。
- 抗菌平板计数。
- 细菌形态 SEM。
- 划痕或迁移。

建议先把安全性排在前面，再讲抑菌和迁移，这样更符合医学审稿人的阅读习惯。

### 4.5 机制桥梁图

适合第五张图。

推荐顺序：

- ROS 染色或流式。
- 缺氧标志物。
- 免疫荧光。
- Western blot。
- 细胞表型定量。

这一组图的任务是把“材料有效”变成“为什么有效”。

### 4.6 动物疗效图

适合第六张图。

推荐顺序：

- 建模与给药流程。
- 创面连续照片。
- 闭合率曲线。
- 细菌负荷或感染控制。

这里最重要的是时间轴。医学图不是只给终点，要让读者看到疗效如何随时间展开。

### 4.7 组织收口图

适合第七张图。

推荐顺序：

- H&E。
- Masson。
- 免疫荧光或免疫组化。
- 标记物定量。

这一组图要完成最后的证据闭环：炎症是否下降、胶原是否重建、血管是否生成、微环境是否真正被改写。

## 5. 医学组合图与工程图的区别

- 工程图强调结构、拓扑、控制和推理链。
- 医学组合图强调疾病、干预、细胞响应、动物疗效和组织重建。
- 工程图可以更像系统框图，医学组合图必须更像证据链。
- 工程图允许抽象模块较多，医学组合图必须保留代表性生物图像和统计图。

不要把医学组合图做成工程流程图，也不要把工程图做成医学海报。

## 6. 特别标注：医学组合图

**医学组合图**建议默认遵守以下规则：

- 图题要写清疾病场景，不要只写“性能展示”。
- 子图优先使用生物学名词，而不是工程术语。
- 代表图和定量图必须配对。
- 病理、免疫荧光、WB、动物照片必须彼此对得上。
- 图组颜色尽量低饱和、白底、少装饰。
- 图内文字尽量短，长解释放到图注或正文。
- 机制词要克制：没有干预实验时，只能写“提示”“相关”“可能参与”。
- 统计图不能脱离代表图单独存在。

## 7. 医学组合图检查清单

投稿前逐项检查：

- 每张图是否只回答一个问题？
- 每张图是否同时有代表图和定量图？
- 图组顺序是否符合“材料 -> 功能 -> 细胞 -> 动物 -> 组织”？
- 对照组和颜色是否全篇一致？
- 细胞、组织、动物三层证据是否闭环？
- 机制表述是否超过了证据强度？
- 图内文字是否足够短，黑白打印是否还可读？
- 是否存在把工程图思路硬塞进医学论文的情况？

## 8. 可直接复用的图组提示语

给 Codex 或 GPT 做图前规划时，可以直接用这类提示：

- 请按医学组合图逻辑，把这组图排成“材料身份 -> 功能确认 -> 载体适配 -> 体外安全与抑菌 -> 机制桥梁 -> 动物疗效 -> 组织收口”的证据链。
- 每张图只回答一个问题，代表图放前，定量图跟后，解释放在图注或正文。
- 图题要像医学论文，不像工程汇报。
- 保持低饱和白底，尽量让黑白打印也能读懂。

## 9. 这类图最常见的错误

- 图太散，没有主线。
- 只有漂亮图，没有定量图。
- 只有定量图，没有代表图。
- 图题写成了实验清单。
- 机制说得太满，证据却不够。
- 颜色太花，像展示页，不像论文图。
- 同一组对照在不同图里名字不一致。
- 病理图、IF、WB、动物照片彼此断开，读不成闭环。
